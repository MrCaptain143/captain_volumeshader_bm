# Captain VolumeShaderBM Website

GitHub Pages-ready copy of the VolumeShaderBM interface.

## Deploy
1. Create a GitHub repository named `captain.github.io` under your GitHub account.
2. Upload the contents of this folder to the repository root.
3. Enable GitHub Pages from Settings → Pages → Deploy from branch → main → /(root).
4. Your site will be available at `https://captain.github.io/` once GitHub finishes publishing.

The included preview image is `assets/volumeshader-preview.png`.

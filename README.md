# VolumeShaderBM — Own Website

This package keeps the original VolumeShaderBM WebGL shader and adds a new mobile-friendly dashboard as `index.html`.

## GitHub Pages
Upload the contents of this folder to your GitHub repository and enable **Settings → Pages → Deploy from a branch**.

Open the generated GitHub Pages URL. The dashboard automatically loads `volumeshader.html` as the live WebGL renderer.

## Files
- `index.html` — new website/dashboard UI
- `volumeshader.html` — original VolumeShaderBM WebGL shader
- Other files — original project files
